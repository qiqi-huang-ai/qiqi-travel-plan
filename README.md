攻略看了很多，真正出发时还是会遇到问题：一天排太满、孩子走不动、长辈要休息、酒店换了位置、下雨了不知道去哪儿……

**qiqi 旅行规划**不是再给你一堆景点清单。你把自己的情况告诉它，它会陪你把时间、同行人、预算、交通和想去的地方慢慢理顺，最后交付一份能打开、能分享、出发前也能再检查的行程。

## 它适合什么时候用

### 想出去，但还没想好去哪

只知道“这个周末想放松一下”“国庆想带孩子出去玩”，也完全没问题。告诉它出发地、时间、预算和大概喜欢什么，它会先帮你比较合适的方向，再往下安排。

### 一家人或几个人同行，需求不一样

有人想逛、有人想拍照、有人要带孩子、有人走不了太久——这些都可以直接说。它会把午休、步行、换酒店、早起、行李和返程时间一起考虑，不把所有人塞进一条赶路路线。

### 车票、酒店或天气变了

不需要推倒重来。直接说“第二天想轻松一点”“酒店换到另一个区了”或“下雨怎么办”，它会基于当前版本调整行程，并保留旧版本供你比较。

## 你只要像和朋友聊天一样告诉它

不需要会做表格，也不用先研究一堆旅游攻略。知道多少说多少；车票、酒店还没定，也可以先做计划。

```text
国庆想从深圳去厦门玩 4 天，2 个大人带一个 4 岁孩子。
人均预算 3000，想坐高铁，节奏轻松一点；鼓浪屿一定要去。
现在车票和酒店都还没订，最后给我一份手机上能打开的行程。
```

它会在真正开始前，把日期、同行人、预算、已订安排和你还没确定的部分问清楚。遇到“4 天 3 晚”和日期对不上、必去点与返程冲突这类情况，也会先和你确认，而不是悄悄替你改掉。

## 它会帮你把哪些事理清

| 旅行里的烦心事 | 你会得到什么 |
| --- | --- |
| 不知道先去哪、怎么玩才顺 | 从出发到返程的每日安排：去哪儿、什么时候出发、路上怎么衔接、哪里可以歇一歇。 |
| 每个人节奏不同 | 把孩子午休、长者体力、连续步行、早起意愿和换酒店需求放进计划里。 |
| 担心预算越玩越超 | 分开看交通、住宿、门票、吃饭和机动费用；已付和待付不会混在一起。 |
| 预约、开放时间、路线总在变 | 把已经确认、还要核对、暂时未知的事分开写，出发前知道该检查什么。 |
| 不想一直翻聊天记录 | 把整份计划做成离线网页，手机或电脑双击就能看。 |

## 最后你会拿到什么

**一份文字攻略，一份随手能看的旅行页面。** 两份内容来自同一份计划：改一次，路线、预算和清单一起更新。

- **Markdown 攻略**：方便你阅读、和同行人讨论、存进笔记。
- **离线 HTML 行程页**：下载后双击打开；可以按天看路线，查看预算、预约提醒和出发前清单。
- **复查清单**：把临近出发仍需要确认的船票、开放时间、天气或车次单独列出来。

## 三步开始

1. 新开一个 Codex 对话，直接说：

   ```text
   请从 https://github.com/qiqi-huang-ai/qiqi-travel-plan 安装 qiqi 旅行规划 Skill。
   ```

   安装完成后，新开一个对话即可使用。若你的 Codex 无法从链接安装，再下载 ZIP，解压后把 `travel-plan-pro` 放进项目的 `.codex/skills/` 目录。

2. 在新对话里说：

   ```text
   请使用 $travel-plan-pro，帮我规划一次旅行。
   ```

3. 像上面一样告诉它旅行需求，边聊边把计划定下来。

## 要不要接 TikHub？你可以自己选

第一次使用时，它会先问你要不要接 TikHub，而不是默认调用。

- **这次不接**：照样能完成基础旅行计划；只是近期排队、亲子体验、餐厅避雷这类游客经验会少一些。
- **已有配置，想接入**：在你同意的请求预算内，补充公开小红书里的体验线索。
- **还不懂怎么配**：可以先让它解释能做什么、可能产生什么成本，再决定是否配置。

无论选哪种，它都不会替你订票、付款或预约；也不会把一条社媒笔记当成景点开放、票价或预约名额的最终答案。
