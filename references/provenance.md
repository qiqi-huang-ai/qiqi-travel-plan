# provenance.md · 独立实现与发布边界

## 独立性

Travel Plan Pro 是独立实现的旅行规划 Skill。其运行、测试和渲染只依赖本包文件，不依赖外部参考 Skill 的目录、代码、模板、测试或品牌资产。

本包的设计重点是：以 `trip.json` 为唯一业务源，分离事实、体验、估算、冲突和未知；把 Provider 授权、版本、重查、隐私投影和离线交付纳入可验证流程。

## 发布前检查

1. 运行 `python3 scripts/release_check.py`，确认必要文件、链接、源码语法、生成文件和行为测试均通过。
2. 运行 Skill 制作工具的 `quick_validate.py`，确认入口 frontmatter 合法。
3. 公开分享行程时，从私有真源生成 `public` 投影，再对投影单独校验和渲染。
4. 只有真实成功调用的 Provider 才能在交付中标为已使用；dry-run、mock、文档声明和测试不等于真实调用。
5. 许可证中的版权主体必须由实际发布者确认；不要沿用不属于本发布者的版权声明。

## 不作出的声明

- 不承诺自动订票、付款、预约、改签或发送消息。
- 不把社媒体验样本当作开放、票价、余量、路线或天气的官方证明。
- 不因 CI 配置存在而声称所有平台已经实际验证；三平台结论须以真实 CI 结果为准。
